# Textmob \n\nTextmob is an expressive and robust communication web application bringing people closer together with real-time features. Build with Node.js and Express, the application serves as a social platform with a rich collection of powerful features.\n\n## Summary\n\nThis application is a robust Express-based server powering the Textmob social platform. Features include:\n* **Real-time Messaging** (via Socket.IO)\n* **Database and Authentication** integrated with Supabase.\n* **Post and Event Management** with JSON-LD SEO optimizations for bots and generic users.\n* **Email Notifications** sent via Nodemailer for critical account changes and custom activities.\n* **Media Uploads** powered directly through Cloudinary in combination with Multer.\n* **Virtual Currency** (Mobcoins) handled and updated on the backend securely.\n* **Password Resets** sent directly to the user's email securely with temporary 15 minute lifespan codes.\n\n## Requirements\nThis app is powered by the Node/npm ecosystem, featuring core libraries like `express`, `@supabase/supabase-js`, `cloudinary`, `socket.io`, `nodemailer` and many more.\n\n## Getting Started\nFirst, install all of the application's dependencies by running:\n\n```bash\nnpm install\n```\n\nTo run the application locally or view scripts, please use standard Node.js mechanisms. The app handles incoming webhooks and connects across various microservices to provide an optimal messaging experience.
